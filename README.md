EcoFarmApp — Программный комплекс на C# с ИИ-модулем

Автоматизированная система для эко-фермы с интегрированными алгоритмами нейронных сетей и базой данных SQL.

Технологический стек:
Язык программирования: C# (.NET Framework / .NET Core)
Архитектура: ООП, SOLID, паттерны проектирования
База данных: SQL (PostgreSQL / SQL Server)
Интерфейс: Desktop UI (WPF / Windows Forms)

Основной функционал:
Обработка и анализ данных с помощью СУБД.
Модуль аналитики: Обработка и визуализация показателей системы.

Клонировать репозиторий.
Открыть файл `EcoFarmApp.sln` в Visual Studio.
Настроить строку подключения к базе данных.
Нажать `F5` для сборки и запуска.
